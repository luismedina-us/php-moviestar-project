# Projeto MovieStar PHP

Projeto de catálogo e avaliação de filmes desenvolvido durante meus estudos de PHP através de um curso de desenvolvimento web.

A aplicação permite o cadastro de usuários, gerenciamento de filmes, publicação de avaliações e comentários, além da edição de informações do perfil.

Durante o desenvolvimento, também realizei ajustes e melhorias para reforçar meus conhecimentos em desenvolvimento backend, banco de dados e organização de aplicações web.

## Tecnologias utilizadas

- MySQL
- PDO
- Bootstrap

## Como executar

### Linux

Clone este repositório:

```bash
git clone https://github.com/luissmedina-dev/php-moviestar-project.git
```

Configure o banco de dados MySQL e execute o projeto em um servidor PHP local.

### Windows

#### Requisitos

- XAMPP ou WAMP

#### Passos

1. Clone o repositório:

```bash
git clone https://github.com/luissmedina-dev/php-moviestar-project.git
```

2. Coloque a pasta do projeto dentro de:

```text
htdocs
```

3. Inicie o Apache e o MySQL

4. Importe o arquivo `.sql` do projeto no phpMyAdmin

5. Configure o arquivo de conexão com o banco de dados

6. Acesse:

```text
http://localhost/php-moviestar-project
```

### macOS

Utilize MAMP ou o servidor embutido do PHP.

Execute no terminal:

```bash
php -S localhost:8000
```

Acesse:

```text
http://localhost:8000
```
